# Youtube Ad-Free Video

Click the extension icon, then click **Open ad-free video** to redirect the
current YouTube video to its matching `yout-ube.com` embed page. You can also
open a video directly from its three-dot menu on the YouTube home and search
pages by selecting **Open Ad-Free Video**. This option is added to videos as
they load, including when you scroll for more results.

Example:

- `https://www.youtube.com/watch?v=1234567890`
- opens `https://www.yout-ube.com/embed/1234567890`

## Download and install in Chrome

1. On the GitHub repository page, click **Code**, then **Download ZIP**.
2. Extract the downloaded ZIP file. Chrome needs the extracted folder; do not
   select the ZIP file itself.
3. In Chrome, open [`chrome://extensions`](chrome://extensions).
4. Turn on **Developer mode** using the switch in the top-right corner.
5. Click **Load unpacked**.
6. Select the extracted `youtube-ad-free-video` project folder containing
   `manifest.json`.
7. Pin the extension from Chrome's Extensions menu if you want quick access.

## Open a video from its three-dot menu

1. Open the YouTube home page or search results.
2. Click the three-dot menu next to a video.
3. Select **Open Ad-Free Video** to open that video on its matching ad-free
   page.

## Use the extension popup

1. Open a YouTube video page.
2. Click the extension icon in Chrome's toolbar.
3. Click **Open ad-free video**.

On other pages, the popup displays a message instead of the redirect button.
